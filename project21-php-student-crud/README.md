# Project 21 - PHP Student CRUD (Responsive)

## Description
A responsive PHP website for managing student records with full CRUD operations (Create, Read, Update, Delete).

## Tech Stack
- PHP, MySQL
- XAMPP Apache + MySQL

## Prerequisites
- XAMPP Apache running on port 8081
- XAMPP MySQL running

## Setup
Visit init_db.php first:
http://localhost:8081/project21-php-student-crud/init_db.php

## URL
http://localhost:8081/project21-php-student-crud/index.php

## Database
- Database: `student_crud_db`
- Table: `students` (id, name, email, course, phone, created_at)
- View in phpMyAdmin: http://localhost:8081/phpmyadmin

## Features
- Add new student records
- View all students in a responsive table
- Edit existing student records (inline form)
- Delete student records with confirmation
- Responsive layout (works on mobile)
- Sample data pre-loaded on first run
