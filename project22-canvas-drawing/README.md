# Project 22 - HTML Canvas Drawing Tool

## Description
A responsive HTML canvas drawing application. Users can draw lines, rectangles, circles, and freehand shapes using mouse click and drag events.

## Tech Stack
- HTML5 Canvas, JavaScript
- No server required

## How to Run
Open directly in browser:
Double-click index.html

## Features
- Draw shapes: Line, Rectangle, Circle, Freehand
- Color picker
- Line width selector
- Live preview while dragging
- Clear canvas button
- Responsive canvas
