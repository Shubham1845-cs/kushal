# Project 23 - jQuery Style Switcher

## Description
A jQuery application with three style buttons. Each button applies a different theme (Blue, Green, Dark) to all controls on the page.

## Tech Stack
- HTML, CSS, jQuery 3.7.1 (CDN)

## How to Run
Open directly in browser (requires internet for jQuery CDN):
Double-click index.html

## Features
- Style 1: Blue Theme (Arial font, blue colors)
- Style 2: Green Theme (Georgia font, green colors)
- Style 3: Dark Theme (Courier New font, dark background)
- Applies style to all inputs, selects, textareas, buttons, headings
