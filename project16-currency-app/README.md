# Project 16 - React Currency Converter (Vite)

## Description
A React application that converts US Dollars to Indian Rupees using React useState Hook.

## Tech Stack
- React 18, Vite
- useState Hook

## Prerequisites
- Node.js installed

## Setup & Run
```bash
npm install
npm run dev
```

## URL
http://localhost:5173 (or next available port)

## Features
- Input amount in USD
- Convert to INR using fixed exchange rate (1 USD = 83.5 INR)
- Input validation
- Reset button
- Uses React useState for state management
