# Project 29 - React Digital Clock (Vite)

## Description
A real-time digital clock built with React Hooks that updates every second.

## Tech Stack
- React 18, Vite
- useState, useEffect Hooks

## Prerequisites
- Node.js installed

## Setup & Run
```bash
npm install
npm run dev
```

## URL
http://localhost:5174 (or next available port)

## Features
- Real-time clock updating every second
- Displays time in HH:MM:SS format
- Shows current date and day
- Start/Stop button to control the clock
- Green color when running, red when stopped
- Uses useState to store current time
- Uses useEffect with setInterval for updates
- Cleanup on component unmount
