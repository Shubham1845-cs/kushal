# Project 25 - Traffic Signal System

## Description
A responsive traffic signal system with glowing LED lights for 4 directions (North, East, South, West). Supports manual and auto mode.

## Tech Stack
- HTML, CSS, JavaScript
- No server required

## How to Run
Open directly in browser:
Double-click index.html

## Features
- 4 traffic signals (North, East, South, West)
- Glowing LED effect for active signal
- Manual mode: Red, Yellow, Green buttons
- Auto mode: cycles Red(10s) → Yellow(3s) → Green(10s) → Yellow(3s)
- Stop Auto button
- Countdown timer showing next signal change
- Signal info table
