# Project 11 - PHP Session Limit

## Description
A PHP login system with session timeout. Sessions expire after 5 minutes of inactivity.

## Tech Stack
- PHP, Sessions
- XAMPP Apache

## Prerequisites
- XAMPP Apache running on port 8081

## URL
http://localhost:8081/project11-php-session-limit/login.php

## Pages
- login.php - Login page
- dashboard.php - Dashboard (session protected)
- logout.php - Logout
- refresh_session.php - Refreshes session on activity

## Features
- Session timeout after 5 minutes
- Countdown timer on dashboard
- Auto redirect on session expiry
- No database required (session only)
