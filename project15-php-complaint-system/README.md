# Project 15 - PHP Complaint Management System

## Description
A complaint management system where students can register, login, and submit complaints. Admin can view and manage all complaints.

## Tech Stack
- PHP, MySQL
- XAMPP Apache + MySQL

## Prerequisites
- XAMPP Apache running on port 8081
- XAMPP MySQL running

## Setup
Visit init_db.php first:
http://localhost:8081/project15-php-complaint-system/init_db.php

## Default Admin Credentials
- Username: admin
- Password: admin123

## URLs
- Student Register: http://localhost:8081/project15-php-complaint-system/student_register.php
- Student Login: http://localhost:8081/project15-php-complaint-system/student_login.php
- Student Dashboard: http://localhost:8081/project15-php-complaint-system/student_dashboard.php
- Admin Login: http://localhost:8081/project15-php-complaint-system/admin_login.php
- Admin Dashboard: http://localhost:8081/project15-php-complaint-system/admin_dashboard.php

## Database
- Database: `complaint_db`
- Tables: `users`, `complaints`
- View in phpMyAdmin: http://localhost:8081/phpmyadmin
