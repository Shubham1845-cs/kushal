# Problem 5 - PHP MySQL

## Description
A PHP application that connects to MySQL and performs database operations.

## Tech Stack
- PHP, MySQL
- XAMPP Apache + MySQL

## Prerequisites
- XAMPP Apache running on port 8081
- XAMPP MySQL running

## Setup
Run db_setup.sql in phpMyAdmin first:
http://localhost:8081/phpmyadmin

## URL
http://localhost:8081/problem5-php-mysql/index.php
