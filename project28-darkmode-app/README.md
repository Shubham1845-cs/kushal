# Project 28 - React Dark Mode Toggle (Vite)

## Description
A React application that allows users to toggle between Light Mode and Dark Mode using React useState Hook.

## Tech Stack
- React 18, Vite
- useState Hook

## Prerequisites
- Node.js installed

## Setup & Run
```bash
npm install
npm run dev
```

## URL
http://localhost:5173 (or next available port)

## Features
- Toggle button to switch between Light and Dark mode
- useState stores current theme
- Background and text colors change dynamically
- Displays current theme mode name
- Theme persists during component re-render
- Sample form elements styled with current theme
