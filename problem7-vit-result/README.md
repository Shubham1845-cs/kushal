# Problem 7 - VIT Result System

## Description
A PHP application to save and view student results for VIT.

## Tech Stack
- PHP, MySQL
- XAMPP Apache + MySQL

## Prerequisites
- XAMPP Apache running on port 8081
- XAMPP MySQL running

## URLs
- Save Result: http://localhost:8081/problem7-vit-result/index.html
- View Results: http://localhost:8081/problem7-vit-result/view-results.php
