# Project 24 - JavaScript Age Calculator

## Description
A JavaScript application that accepts a birth date and calculates the exact age in years, months, and days format.

## Tech Stack
- HTML, CSS, JavaScript
- No server required

## How to Run
Open directly in browser:
Double-click index.html

## Features
- Date of birth input with max date set to today
- Calculates age in Years, Months, Days
- Shows total days lived
- Shows days until next birthday
- Input validation (future date check)
