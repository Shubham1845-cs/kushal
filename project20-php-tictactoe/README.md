# Project 20 - PHP Tic-Tac-Toe Game

## Description
A two-player Tic-Tac-Toe game built with PHP and sessions. Players take turns clicking cells on a 3x3 board.

## Tech Stack
- PHP, Sessions
- XAMPP Apache

## Prerequisites
- XAMPP Apache running on port 8081

## URL
http://localhost:8081/project20-php-tictactoe/index.php

## Features
- Two-player game (X and O)
- Win detection for all 8 combinations
- Draw detection
- Score tracking across games
- New Game button (resets board, keeps scores)
- Reset Scores button (resets everything)
- No database required (uses PHP sessions)
